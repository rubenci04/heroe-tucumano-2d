# Plan de producción artística V2

## Regla de sustitución

Cada bloque crea primero los archivos V2 dentro de `art_v2/`, los valida en una captura de referencia a 800×450 y sólo después habilita una tarea separada de integración. Los assets legacy se conservan como referencia durante todo el proceso.

## Dependencias de producción

Los bloques 1 y 2 fijan escala, paleta y lenguaje de animación para todo el reparto. Los bloques 3–6 deben respetarlos. Escenario, props, UI y VFX se producen contra esa guía; su integración no empieza hasta que sus paquetes V2 estén aprobados. El audio queda último porque no requiere reemplazar arte ni reabrir decisiones de silueta.
